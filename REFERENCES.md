## Important provenance statement

The PANOPTICON-inspired model in this repository is a **classroom reimplementation** motivated by the published architecture/task. It is not the Vivien et al. code and does not use their weights.

The ExoMiner++ teaching segment is designed to use the **official NASA ExoMiner implementation externally**. NASA source code is not copied into this repository.

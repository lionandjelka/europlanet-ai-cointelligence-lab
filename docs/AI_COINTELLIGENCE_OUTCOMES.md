# AI co-intelligence learning outcomes

By the end of this practical, students should be able to:

1. **Work with AI as a scientific reasoning partner rather than a black-box classifier.** Combine physical knowledge, statistical diagnostics, model outputs, and human judgement.
2. **Separate data, representation, prediction, and scientific inference.** Track how information changes from measured light curve to derived statistic, neural representation, probability score, and decision.
3. **Evaluate what an AI system knows — and what it does not know.** Distinguish observed evidence, training-set prior information, and information absent from the measurement.
4. **Recognize inductive bias.** Compare periodic templates, local convolutional morphology, multi-diagnostic vetting, and context-conditioned relational inference.
5. **Develop representation awareness.** Ask which relations are preserved or destroyed by each representation.
6. **Diagnose failure modes.** Identify stellar-activity false positives, target leakage, domain shift, missing context, representation loss, and overconfidence.
7. **Reason with uncertainty.** Interpret thresholds, ROC/AUC, predictive distributions, disagreement, and incomplete evidence.
8. **Use model disagreement as scientific information.** Investigate why different methods disagree and what additional data would distinguish the hypotheses.
9. **Understand relational intelligence.** Explore how local/attentive inference uses relationships among context observations rather than isolated points.
10. **Distinguish pattern recognition from physical explanation.** A correct classification does not automatically identify the physical cause.
11. **Recognize information limits.** AI cannot reliably manufacture object-specific evidence that was not preserved in the observations.
12. **Practice human–AI co-decision making.** Allocate limited follow-up resources by combining model outputs, physics, uncertainty, and scientific value.
13. **Formulate the next observation.** Move from “What does the model predict?” to “What measurement would most reduce uncertainty?”

| Section | Co-intelligence gain |
|---|---|
| Information chain | Audit the evidence that reaches an AI system |
| Data inspection | Catch leakage and representation problems before modelling |
| BLS | Challenge a high algorithmic score using physical/noise context |
| PANOPTICON-inspired detector | Compare inductive biases and exploit disagreement |
| ExoMiner++ | Integrate heterogeneous diagnostic evidence for vetting |
| Local Neural Process | Test what can and cannot be inferred from available context |
| Mission board | Make joint human–AI decisions under resource constraints |
| Exit ticket | Define what a scientifically useful AI representation should preserve |
